**Status:** human-owned preparation artifact — not approved and not a substitute
for the final report, pitch, or mentor review.

Use this file to collect the contribution text that the team has actually
approved. Do not infer a person's role, effort, or percentage from Git commit
counts, file ownership, or an agent's summary. Do not place passwords, access
tokens, invite links, private contact details, or demo-account credentials in
this repository.

## Contribution wording rules

- Use first-hand, specific statements that the named member has approved.
- Describe shipped behavior, research, design, testing, documentation, or
  coordination only when the member confirms it.
- Do not infer percentages from Git history. Add percentages only if the team
  explicitly agrees to them and records that approval here.
- Keep capability, privacy, deployment, pilot, and impact wording aligned with
  `final-report-content.md`, `pitch-claims-brief.md`, and the claims validator.
