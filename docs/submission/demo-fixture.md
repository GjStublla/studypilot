# Golden-flow demo fixture

**Status:** Synthetic content only. Creating the hosted demo account and
loading this data remain human-owned release steps.

Use this fixture for the two-minute ceremony path. It contains no real student
data, credentials, or hosted identifiers.

## Rubric

**Title:** Argument clarity mini-rubric

| Criterion | Description |
|---|---|
| Claim | States one specific, debatable claim rather than a broad topic. |
| Evidence | Connects one concrete example to the claim and explains why it matters. |
| Reasoning | Acknowledges a reasonable counterpoint and answers it. |

## Deliberately weak paragraph

> Social media is bad for students because it distracts them. Many people use
> it every day, and it can waste time. Schools should probably limit it so
> students can focus more.

## Demo prompt sequence

1. **Initial question:** “What should I revise first in this paragraph using the rubric?”
2. **Socratic follow-up:** “What evidence would make the claim more specific without writing the paragraph for me?”
3. **Action item:** “Rewrite the claim so it names the student outcome and one condition.”

## Expected visible checkpoints

- The extension shows the selected page context and the active rubric title.
- The coaching response names at least one rubric criterion and proposes a
  next revision step; it does not claim perfect accuracy or a measured grade
  improvement.
- One action item is created with the text above.
- With **Save to dashboard** enabled, the same chat/action item appears in the
  dashboard. Screenshot capture remains off unless the recording explicitly
  needs it.

## Recording setup

- Use text input as the primary path and keep microphone Live as an optional
  fallback only after hosted Live is verified.
- Use a clean Chrome profile, no personal tabs, and a demo account with one
  existing chat and one empty action-item slot.
- Record a second run and retain a backup video/screenshots outside Git.
