## Evidence rules for Grok

1. Never turn a local fixture, placeholder URL, axe result, test count, or preview Lighthouse run into a hosted or causal claim.
2. Show the exact commit or artifact behind each technical statement; use the current canonical extension head `219c44d` and the web baseline documented in the checklist.
3. Keep the privacy statement consistent: microphone audio is processed by Vertex AI during Live; screenshots and dashboard persistence are independently opt-in and default off.
4. If a human-owned gate is still open, record the owner, prerequisite, and exact command instead of marking it passed.
