# StudyPilot two-minute demo script

**Target length:** 1:58 maximum
**Status:** Script/template; record only after the deployed golden flow is verified.

Synthetic rubric, paragraph, prompt sequence, and checkpoint expectations are
in [`demo-fixture.md`](demo-fixture.md). The fixture is content-only; it does
not replace a hosted demo account or pilot result.

| Time | On screen | Spoken point |
|---|---|---|
| 0:00–0:12 | Weak paragraph and rubric | The problem is fragmented browser context, rubric criteria, and follow-up work. |
| 0:12–0:28 | Upload/select the short rubric | StudyPilot makes the rubric part of the coaching context. |
| 0:28–0:48 | Extension on the study page | Share only the chosen page context and ask about the weak paragraph. |
| 0:48–1:13 | Grounded response and Socratic follow-up | Show the criterion-linked feedback and one follow-up question; do not claim perfect accuracy. |
| 1:13–1:31 | Save one action item | Turn the next revision into a durable task. |
| 1:31–1:47 | Open the same chat/session in the dashboard | The conversation and action item continue across surfaces when persistence is enabled. |
| 1:47–1:58 | Approved pilot result or qualified limitation | State one measured result, or explicitly say pilot evidence is not yet available. |

## Recording rules

- Use a deterministic demo account with a short rubric and no personal data.
- Record the deployed beta, not only mocks or local fixtures.
- Keep a text-input fallback and a backup recording.
- Remove credentials, unrelated tabs, debug UI, loading pauses, and personal content.
- Record the same flow twice from a clean Chrome profile before final submission.
